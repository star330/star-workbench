# 【星光不负赶路人】个人工作台使用说明

这是一个本地版 PWA 个人备考工作台，适合 2027 广东国考行政执法卷与广东省考备考使用。

## 如何打开

1. 直接打开 `index.html` 可以使用大部分功能。
2. 如果要体验“添加到手机桌面”和离线缓存，建议通过本地服务器或部署到静态网站后访问，因为浏览器通常不允许从普通文件路径安装 PWA。

## 已实现功能

- 时政热点与逻辑填空精析：每天自动生成 3 条示例热点，可手动新增、删除、替换为真实来源。
- 越做越行：内置行测六大板块题型框架，支持题库增删、按板块/题型抽取 5 题训练、提交后显示解析。
- 申论点拨：内置行政执法卷能力框架，支持按“段落、句子、关键词、入选原因、规范答案点”记录材料解析。
- 错题分类专项复盘：训练错题自动沉淀，也可手动记录错因、避坑点和正确路径。
- 知识导入：支持导入文本类思维导图或手动粘贴知识摘要。
- 数据分析：根据做题结果生成六大板块掌握度百分比、星级和雷达图。

## 重要说明

- 所有数据默认保存在当前浏览器本地，清理浏览器缓存可能导致数据丢失。
- 当前版本不直接联网抓取真实时政或真题，避免来源不稳定和版权风险。你可以把权威来源、真题材料或自己的思维导图导入工作台。
- 若需要每天真正自动更新实时热点，可以后续接入新闻源/API，或让我为你创建一个每日自动化任务，把当天 3 条热点整理成可导入内容。
